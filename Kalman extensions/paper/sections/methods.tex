\section{Methods}
\label{sec:methods}

The observation model in the linear Gaussian case is
\begin{equation}
\label{eq:obs}
f_t^{(\theta)}(y_t \mid x_t) = \mathcal{N}(y_t; Hx_t, R).
\end{equation}
An ensemble of size \(N\) is propagated by the state transition. The forecast mean \(\hat{\mu}_{t\mid t-1}\) and covariance \(\hat{\Sigma}_{t\mid t-1}\) are the sample moments, with divisor \(N-1\). The ensemble Kalman likelihood contribution is
\begin{equation}
\label{eq:enkf-lik}
\hat{p}_{\mathrm{enkf},t}^{(\theta)}(y_t \mid y_{0:t-1})
  = \mathcal{N}\bigl(y_t; H\hat{\mu}_{t\mid t-1},\, H\hat{\Sigma}_{t\mid t-1}H^{\top}+R\bigr).
\end{equation}
This contribution is exact for the Gaussian forecast approximation and is not unbiased for the true predictive density. The product of these contributions, multiplied by the prior, defines \(\hat{\pi}_{\mathrm{enkf},t}\) up to the ensemble randomness carried by the extended target of \citet[Section~4.1]{golightly2026}. The exact posterior at the same time is \(\pi_t(\theta \mid y_{0:t})\). The first error is the difference between these two distributions.

\subsection{Plain nested filter}

The outer recursion follows Algorithm~6 of \citet{golightly2026}. At time \(t\), each parameter particle is updated by one ensemble Kalman step and its weight is multiplied by \eqref{eq:enkf-lik}. If the effective sample size is at least \(\gamma M\), the cloud is left as it is. Otherwise the particles are resampled with replacement, the weights are reset to \(1/M\), and each particle is offered one Metropolis--Hastings proposal. The proposal is a random walk whose covariance is \(\zeta\) times the sample covariance of the other resampled particles. In the studies below, \(\zeta^{2} = 2.56^{2}/d_{\theta}\) and the ensemble size is held fixed. The acceptance ratio uses the prior and the ensemble Kalman likelihood of the series so far. The likelihood at a proposed value is obtained by rerunning the filter from the known initial condition.

The printed Algorithm~6 places the effective-sample-size test inside the particle loop. The surrounding text applies one resample-move step when the effective sample size of the updated cloud falls below \(\gamma M\). We follow the surrounding text.

For the nonlinear Gaussian observation in Section~\ref{sec:sim}, the matrix \(R\) in \eqref{eq:enkf-lik} is replaced by the scalar \(\tilde{R} = H\hat{\mu}_{t\mid t-1}\), as in Section~5.2 of \citet{golightly2026}. The plain filter then targets \(\hat{\pi}_{\mathrm{enkf}}\) under that choice. It does not evaluate the true observation density.

\subsection{Rao-Blackwellised weight}

For a general observation density \(f\), the filter can still be run under a linear Gaussian approximation \(g_t^{(\theta)}(y_t \mid x_t) = \mathcal{N}(y_t; \tilde{H} x_t, \tilde{R})\). The Rao-Blackwellised increment averages, over the analysis ensemble, the terms
\begin{equation}
\label{eq:rb}
\hat{g}_{\mathrm{enkf},t}^{(\theta)}(y_t)\, \frac{f_t^{(\theta)}(y_t \mid x_t^{j})}{g_t^{(\theta)}(y_t \mid x_t^{j})}.
\end{equation}
The parameter target induced by these increments is \(\tilde{\pi}_{\mathrm{enkf},t}\). The ratio \(f/g\) puts the true observation density back. The Gaussian forecast remains, so \(\tilde{\pi}_{\mathrm{enkf},t}\) is not \(\pi_t\).

\begin{lemma}
\label{lem:identity}
If \(f_t^{(\theta)} = g_t^{(\theta)}\), the Rao-Blackwellised increment equals the ensemble Kalman increment \eqref{eq:enkf-lik}.
\end{lemma}

The ratio in \eqref{eq:rb} is then equal to 1 for every analysis member, and the average of those terms is the predictive likelihood under \(g\), which is \eqref{eq:enkf-lik}. The incremental weights agree, and so do the parameter targets. Evaluating the ratio costs an extra density for each ensemble member and does not change the estimate. The cancellation uses equality of the two observation densities. It does not, by itself, describe a nonlinear observation.

In the Lotka--Volterra comparison the true density \(f\) is Gaussian with variance equal to the prey component. The plain filter uses \(\tilde{R} = H\hat{\mu}_{t\mid t-1}\). The Rao-Blackwellised filter uses the same quantity multiplied by 2, which is the inflation stated in Section~5.2 of \citet{golightly2026}, and it evaluates \(f/g\) at the analysis members. Vanilla SMC2 does not use \(g\). Its state weight is \(f\), its proposal is the Euler--Maruyama transition, and its parameter target is \(\pi_t\).

\subsection{Nearest-neighbour weight}

If the incremental weight is a nearest-neighbour prediction of \eqref{eq:enkf-lik}, the weights target
\begin{equation}
\label{eq:knn-target}
\pi_{\mathrm{knn},t}(\theta) \propto \pi(\theta)\, \exp\bigl(\ell_{\mathrm{knn},t}(\theta)\bigr),
\end{equation}
conditional on the stored cloud that defines the surrogate log-likelihood \(\ell_{\mathrm{knn},t}\). This is the second error. Equation~\eqref{eq:knn-target} is not \(\hat{\pi}_{\mathrm{enkf},t}\), and a comparison of \(\pi_{\mathrm{knn},t}\) with \(\pi_t\) mixes the two errors.

In the linear Gaussian pilot the first \(k\) particles are a reference set and are always updated with the ensemble Kalman filter. Every other particle takes the inverse-distance prediction of the reference increments. The diagnostic, fixed before that run, recomputes \eqref{eq:enkf-lik} for eight non-reference particles at the terminal time. The surrogate increment was to be called a poor approximation of the ensemble Kalman increment if the mean, over replicates, of the median absolute log difference exceeded 1.

A uniform bound \(\delta\) on \(|\ell_{\mathrm{knn},t}(\theta) - \ell_{\mathrm{enkf},t}(\theta)|\) over the prior support would imply that the total variation distance between the two posteriors built from those fixed log-likelihoods is at most \(\min\bigl(1, (e^{2\delta}-1)/2\bigr)\). The short calculation is recorded in the theory note of 15 October 2026. The hypothesis was not proved. The ensemble Kalman log-likelihood is a random function of the ensemble, the diagnostic is not a uniform \(\delta\), and no Lipschitz constant for that log-likelihood was available from the papers we used. The diagnostic remains the comparison we report. We do not state a theorem for the distance.

The same pilot also compared an exact tree with a list, a kernel switch that depends only on time, and a finite-difference random-walk proposal. Those comparisons are not part of the claim. The finite-difference proposal leaves \(\hat{\pi}_{\mathrm{enkf}}\) invariant when the Gaussian proposal density is included in the acceptance ratio, and the pilot did not support it on effective sample size per transition draw.
