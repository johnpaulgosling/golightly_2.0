\section{Related work}
\label{sec:related}

SMC2 propagates a cloud of parameter particles, and each particle carries a particle filter. The incremental weight is an unbiased estimate of the likelihood contribution. \citet[Proposition~1]{chopin2012} write the extended target so that its \(\theta\)-marginal is the exact parameter posterior for any fixed number of state particles. The rejuvenation kernel is particle Metropolis--Hastings on that extended target. Replacing the inner particle filter by an ensemble Kalman filter removes the unbiasedness on which this marginal property rests, and the marginal is then \(\hat{\pi}_{\mathrm{enkf}}\).

Ensemble Markov chain Monte Carlo uses the same ensemble Kalman likelihood inside one Metropolis--Hastings chain on a fixed data set \citep{drovandi2022}. One rejuvenation sweep of the nested filter is one iteration of that scheme, but the chain itself is not sequential. Even when the forecast is exactly Gaussian, the plug-in Gaussian density is a biased estimator of the idealised Gaussian predictive. An unbiased estimator of that Gaussian density does not restore the exact posterior of the state-space model.

A different sequential construction gives the parameter an artificial transition and resamples it with a shrinkage kernel, so that the filter does not collapse onto a single parameter value \citep{liu2001}. The particle ensemble Kalman filter of \citet{katzfuss2018} weights parameter particles by an integrated ensemble Kalman likelihood. For a constant parameter they return to that kernel, because a point-mass proposal would otherwise leave fewer and fewer distinct particles. The nested filter keeps \(\theta\) static and restores diversity by a Metropolis--Hastings move.

Delayed acceptance screens a proposal with a cheap approximation and then corrects the screen with the intended target \citep{christen2005}. If the parent kernel is irreducible for that target, the proposal is reversible, and the approximation is positive wherever the proposal is positive, the target remains invariant. \citet{sherlock2016} store the expensive evaluations in a KD-tree and use an inverse-distance neighbour average as the screen, inside batch Markov chain Monte Carlo. \citet{bon2021} put a surrogate inside the mutation of a sequential Monte Carlo sampler for a static model. In both cases the second stage evaluates the expensive target. \citet[Section~5.1]{sherlock2016} contrast this with algorithms that target the approximate posterior itself, and that is the distinction drawn for the surrogate weight in Section~\ref{sec:methods}.

\citet[Proposition~2]{katzfuss2018} show that, in their Example~5, the variance of the log ensemble Kalman likelihood is of order \(n/N\) when the forecast members are drawn independently from the true forecast, with \(n\) the observation dimension in that example. \citet{golightly2026} cite this scaling. The argument is for that example and for independent forecast draws, and it does not cover the nested filter. \citet{temfack2026} also replace the inner particle filter of SMC2 by an ensemble Kalman filter. Their observation variance depends on the state, they use an unbiased Gaussian density estimator, and they are explicit that the Gaussian assumption remains. The mutation is particle marginal Metropolis--Hastings. They do not use delayed acceptance or the Rao-Blackwellised weight studied here.

Adaptive sequential Monte Carlo can choose among kernels that each leave the current target invariant, with the tuning carried as an auxiliary variable and with kernels scored by expected squared jumping distance \citep{fearnhead2010}. A later SMC2 construction switches between particle marginal Metropolis--Hastings and particle Gibbs \citep{botha2023}. Particle Gibbs needs a conditional particle filter, which an ensemble Kalman filter does not supply, and the unbiasedness used in those arguments is not available for \(\hat{\pi}_{\mathrm{enkf}}\). The switch in Section~\ref{sec:methods} is chosen before the proposal and depends on the series only through time.

\citet[Theorem~3.2]{chen2021} consider linear state transitions and a Gaussian initial distribution, and they prove that the gradient of the ensemble Kalman log-likelihood converges to the true score in \(L^p\) at rate \(N^{-1/2}\). Their algorithm is gradient ascent and has no accept-reject step. A particle-filter gradient inside an uncorrected Langevin proposal \citep{rosato2024} is a derivative of a different likelihood. Section~\ref{sec:sim} reports a corrected finite-difference proposal on the Ornstein--Uhlenbeck pilot, where the exact score is available by other means, and gives the reason that proposal is set aside.
