\section{Related work}
\label{sec:related}

SMC2 propagates a cloud of parameter particles, and each particle carries a particle filter. The incremental weight is an unbiased estimate of the likelihood contribution. \citet[Proposition~1]{chopin2012} write the extended target so that its \(\theta\)-marginal is the exact parameter posterior for any fixed number of state particles. The rejuvenation kernel is particle Metropolis--Hastings on that extended target. Replacing the inner particle filter by an ensemble Kalman filter removes the unbiasedness on which this marginal property rests. The marginal is then \(\hat{\pi}_{\mathrm{enkf}}\), not \(\pi_t\).

Ensemble Markov chain Monte Carlo uses the same ensemble Kalman likelihood inside one Metropolis--Hastings chain on a fixed data set \citep{drovandi2022}. One rejuvenation sweep of the nested filter is one iteration of that scheme, but the chain itself is not sequential. Even when the forecast is exactly Gaussian, the plug-in Gaussian density is a biased estimator of the idealised Gaussian predictive. An unbiased estimator of that Gaussian density, of the kind used by \citet{drovandi2022} and by \citet{temfack2026}, does not restore the exact posterior of the state-space model. It removes a different error from the one that separates \(\hat{\pi}_{\mathrm{enkf}}\) from \(\pi_t\).

A different sequential construction gives the parameter an artificial transition and resamples it with a shrinkage kernel, so that the filter does not collapse onto a single parameter value \citep{liu2001}. The particle ensemble Kalman filter of \citet{katzfuss2018} weights parameter particles by an integrated ensemble Kalman likelihood and, for a constant parameter, moves them with that kernel. The nested filter keeps \(\theta\) static and restores diversity by a Metropolis--Hastings move under \(\hat{\pi}_{\mathrm{enkf}}\).

Delayed acceptance screens a proposal with a cheap approximation and then corrects the screen with the intended target \citep{christen2005}. If the parent kernel is irreducible for that target, the proposal is reversible, and the approximation is positive wherever the proposal is positive, the target remains invariant. \citet{sherlock2016} store the expensive evaluations in a KD-tree and use an inverse-distance neighbour average as the screen, inside batch Markov chain Monte Carlo. \citet{bon2021} put a surrogate inside the mutation of a sequential Monte Carlo sampler for a static model. In both cases the second stage evaluates the expensive target. \citet[Section~5.1]{sherlock2016} contrast this with algorithms that target the approximate posterior itself. The nearest-neighbour weight in Section~\ref{sec:methods} is that second use. It targets \(\pi_{\mathrm{knn}}\). The screen, when it is corrected, does not.

\citet{temfack2026} also replace the inner particle filter of SMC2 by an ensemble Kalman filter, for epidemic incidence, with a state-dependent observation variance. They are explicit that the Gaussian assumption remains. Their mutation is particle marginal Metropolis--Hastings. They do not use the Rao-Blackwellised weight of Section~\ref{sec:methods}, and this paper does not reanalyse an epidemic series.

Two further modifications of the resample-move step are set aside. A kernel switch that depends on a conditional particle filter, as in \citet{botha2023}, is not available once the inner filter is an ensemble Kalman filter, and the unbiasedness used by \citet{fearnhead2010} is not the ensemble Kalman weight. A finite-difference proposal for the gradient of the ensemble Kalman log-likelihood can be corrected by Metropolis--Hastings, in the linear Gaussian case covered by the score result of \citet[Theorem~3.2]{chen2021}, but the pilot comparison did not support the proposal on cost. An uncorrected Langevin proposal \citep{rosato2024} is a derivative of a particle-filter likelihood and is not used.
