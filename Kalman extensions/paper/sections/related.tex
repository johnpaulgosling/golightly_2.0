\section{Related work}

SMC2 propagates a cloud of parameter particles. Each particle carries a particle filter. The incremental weight is an unbiased estimate of the likelihood contribution, and the \(\theta\)-marginal of the extended target is the exact parameter posterior for any fixed number of state particles \citep[Proposition~1]{chopin2012}. The rejuvenation kernel is particle Metropolis--Hastings on that extended target. Replacing the inner particle filter by an ensemble Kalman filter removes the unbiasedness step. The marginal is then \(\hat{\pi}_{\mathrm{enkf}}\).

Ensemble Markov chain Monte Carlo uses the same ensemble Kalman likelihood inside one Metropolis--Hastings chain on a fixed data set \citep{drovandi2022}. One rejuvenation sweep of the nested filter is one iteration of that scheme. The chain is not sequential. Even when the forecast is exactly Gaussian, the plug-in Gaussian density is a biased estimator of the idealised Gaussian predictive, and an unbiased estimator of that Gaussian density does not restore the exact posterior of the state-space model.

A different sequential construction gives the parameter an artificial transition and resamples it with a shrinkage kernel, so that the filter does not collapse onto a single parameter value \citep{liu2001}. The particle ensemble Kalman filter of \citet{katzfuss2018} weights parameter particles by an integrated ensemble Kalman likelihood and, for a constant parameter, points back to that kernel because a point-mass proposal would otherwise leave fewer and fewer distinct particles. The nested filter keeps \(\theta\) static and restores diversity by a Metropolis--Hastings move.

Delayed acceptance screens a proposal with a cheap approximation and corrects it with the intended target \citep{christen2005}. If the parent kernel is irreducible for that target, the proposal is reversible, and the approximation is positive wherever the proposal is positive, the target remains invariant. \citet{sherlock2016} store the expensive evaluations in a KD-tree and use an inverse-distance neighbour average as the screen, in batch Markov chain Monte Carlo. \citet{bon2021} put a surrogate inside the mutation of an SMC sampler for a static model. In both cases the second stage evaluates the expensive target. Using the surrogate as the target is a different algorithm \citep[Section~5.1]{sherlock2016}.

\citet{katzfuss2018} give the variance of the log ensemble Kalman likelihood as of order \(n/N\) in one independent linear example, when the forecast members are drawn independently from the true forecast (their Proposition~2). That is the scaling comparison cited by \citet{golightly2026}. It is not a theorem about the nested filter. \citet{temfack2026} also replace the inner particle filter of SMC2 by an ensemble Kalman filter, with a state-dependent observation variance and an unbiased Gaussian density estimator, and they are explicit that the Gaussian assumption remains. Their mutation is particle marginal Metropolis--Hastings. They do not use delayed acceptance or the Rao-Blackwellised weight studied here.

Adaptive SMC can choose among kernels that each leave the current target invariant, treating the tuning as an auxiliary variable and scoring kernels by expected squared jumping distance \citep{fearnhead2010}. A later SMC2 construction switches between particle marginal Metropolis--Hastings and particle Gibbs \citep{botha2023}. Particle Gibbs needs a conditional particle filter. An ensemble Kalman filter does not supply one, and the unbiasedness used in those arguments is not available for \(\hat{\pi}_{\mathrm{enkf}}\). We use only the idea of a choice made before the proposal.

\citet{chen2021} differentiate the ensemble Kalman log-likelihood by automatic differentiation and ascend on it. In the linear Gaussian case they prove an \(L^p\) rate of \(N^{-1/2}\) for that gradient. The ascent has no accept-reject step. A particle-filter gradient inside an uncorrected Langevin proposal \citep{rosato2024} is a derivative of a different likelihood. We do not use either proposal as a method. Section~\ref{sec:sim} reports a corrected finite-difference proposal and the reason it is not retained.
