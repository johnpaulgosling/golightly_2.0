\title{Extensions of a nested ensemble Kalman filter}
\author{Andrew Golightly\\

\begin{abstract}
State-space models with a static parameter and a latent Markov process have an observed-data likelihood given by an integral over the latent path. Nested particle filters estimate the sequence of parameter posteriors, but a particle likelihood becomes expensive as the observation dimension grows. Replacing each likelihood increment by the Gaussian marginal of an ensemble Kalman forecast gives a nested filter for the posterior induced by that approximation. We compare an exact tree for the neighbour screen, a switch between a random walk and delayed acceptance that depends only on time, a nearest-neighbour surrogate used as the weight and a Rao-Blackwellised correction for a different linear Gaussian observation model. On an Ornstein--Uhlenbeck pilot the tree returns the same neighbours as a list. The switch has a lower cost per accepted move than either kernel alone. The surrogate weight uses fewer transition draws and has a larger error in the posterior means. The correction leaves the weight unchanged when the filter already uses the true observation model. A finite-difference Langevin proposal has a smaller effective sample size per transition draw than the random walk.
\end{abstract}

\noindent\textbf{Keywords:} delayed acceptance, Ornstein--Uhlenbeck process, Rao-Blackwellisation, sequential Monte Carlo, surrogate likelihood
